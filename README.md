# Web Components Library

This library provides a set of reusable web components, built using Angular and is distributed as an npm package.
<!-- CI trigger -->

![Build Status](https://github.com/platform-mesh/portal-ui-lib/actions/workflows/pipeline.yaml/badge.svg)

## Getting Started

### Build

Run `npm run build` to build the project. The build artifacts will be stored in the `dist/` directory.

### Running unit tests

Run `npm run test` to execute the unit tests.
